# Sprint — Finalisation du mobilier réaliste et optimisation

Plan canonique exécutable :
[`plan/design-editor-final-assets-1.md`](../../plan/design-editor-final-assets-1.md).

État : **terminé** le 27 septembre 2026.

Objectif : remplacer les six derniers glyphes vectoriels du plan 2D, préserver
toute la géométrie et les interactions, puis mesurer et réduire le poids des 22
sprites avec un benchmark avant/après reproductible.

Résultat : 22 types sur 22 utilisent un sprite réaliste local, le catalogue
optimisé pèse 27 734 479 octets, les 38 captures finales sont dans
`benchmark/runs/editor-final-assets-v2` et les revues Standards/Spec se terminent
sans défaut. Voir le
[rapport final](../../benchmark/comparisons/editor-final-assets/report.md).
